# Screenshot CI/CD

Folder ini berisi screenshot bukti penerapan CI/CD dan branch protection:

1. `1_ci_check_error.png` - CI check error karena pengujian gagal
2. `2_ci_check_pass.png` - CI check pass karena pengujian lolos
3. `3_branch_protection.png` - Branch protection pada halaman PR

## Cara mendapatkan screenshot:

1. Push kode ke branch `add-awesome-feature`
2. Buat Pull Request ke branch `main`
3. Tunggu GitHub Actions selesai
4. Ambil screenshot sesuai kebutuhan
